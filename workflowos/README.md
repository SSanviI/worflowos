# WorkflowOS

## Overview
WorkflowOS is a **FastAPI‑based** backend that provides an API for AI‑powered, OS‑level workflow automation. It ships with a minimal frontend (under `frontend/`) that communicates with the backend via the `/api/*` endpoints.

## Project Structure
```

├─ backend/               # FastAPI server, database models, API routers
│   ├─ api/               # Individual route modules (events, agent, …)
│   ├─ services/          # Business‑logic helpers
│   ├─ models/            # SQLAlchemy ORM models
│   ├─ schemas/           # Pydantic request/response schemas
│   ├─ config.py          # Path configuration (BASE_DIR, etc.)
│   ├─ database.py        # SQLAlchemy engine & Base

└─ README.md              # You are reading it!
```

## Prerequisites
- **Python 3.10+**
- **Git** (optional, for cloning the repo)
- A **virtual environment** tool (`venv` or `conda`)
- (Optional) **Docker** if you prefer containerised execution

## Setup & Installation
1. **Clone the repository** (or download the ZIP you received):
   ```bash
   git clone <repo‑url> workflowos
   cd workflowos
   ```
2. **Create a virtual environment** and activate it:
   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # macOS / Linux
   source .venv/bin/activate
   ```
3. **Install Python dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Configure environment variables**:
   - Copy the example file:
     ```bash
     cp .env.example .env
     ```
   - Edit `.env` and fill in any required values (e.g., `OPENAI_API_KEY`, database URLs, Gmail OAuth tokens, etc.).
5. **Run database migrations** (creates SQLite DB by default):
   ```bash
   python -c "from workflowos.backend.database import Base, engine; Base.metadata.create_all(bind=engine)"
   ```

## Running the Application
### Development mode (auto‑reload)
```bash
uvicorn workflowos.backend.main:app --reload
```
The API will be available at **http://127.0.0.1:8000** and the static frontend at **http://127.0.0.1:8000/static**.

### Production mode
```bash
uvicorn workflowos.backend.main:app --host 0.0.0.0 --port 8000
```
You can also use a process manager like **gunicorn** or **Docker** for deployment.

## Testing

```bash
pytest
```
All tests under `workflowos/tests/` should pass.
